A single Telegram setup wizard connects a dedicated bot and chat to this project.
It enables task notifications and, when inbound Telegram is enabled, replies and
task control in the same flow. Cezar sends a message when a task needs your input,
reaches review, finishes, fails or is cancelled. Start the server with
`CEZ_WEBHOOKS=1`; task control also requires `CEZ_CHAT_INBOUND=1`.

## Where to find it

Settings → Webhooks → **Telegram** → **Connect Telegram**

## How to use it

1. Create a bot with BotFather and paste its token into the wizard. Confirm that the bot is dedicated to this project and that no other application will poll it.
2. Open the private link Cezar shows and press **Start** in Telegram. This one private **Start** action proves the identity of the person being approved; the wizard discovers the chat without asking you to copy a chat ID.
3. For a group, also confirm that every member can read project messages, then compare the code shown in the wizard with the code the bot sends to the person privately.
4. Choose the optional **Cancel tasks** and **Continue tasks (may incur costs)** permissions, review the shell-access and cost warning, and activate the connection.

> **Good to know**:
> - **Minimal** sends task IDs, statuses and the project ID. **Standard** also sends task titles, questions and error text to the chat.
> - With Standard you can also tick **Include an excerpt of the agent's last message**. When the agent asks in plain text instead of a structured question, the message then shows up to 600 characters of what it last wrote. Known secrets and file paths are removed on a best-effort basis. It is off by default.
> - The token controls the bot. Cezar keeps it in the project secret store and never shows it again after setup.
> - Inbound polling does not start until you explicitly activate the wizard. Use a bot dedicated to Cezar so another application cannot consume its updates.

## Chats and channels

For a group, add the bot and complete the visibility confirmation and private
comparison step in the wizard. A bot cannot open a private conversation, so the
approved person must press **Start** in the private chat. A bot already used by
another app cannot safely poll for Cezar, so use a dedicated bot.

## Messages

Messages show the task status in words, for example
`Status: Waiting for your answer (was running)`. Task text is escaped, link
previews are off and each message stays within Telegram's 4,096-character limit.
A revoked token, a removed bot or an unknown chat suspends the connection. Open
the wizard again to repair it and repeat the identity proof. To answer waiting
tasks or start tasks from the same chat, use the task-control steps in the same
wizard; there is no separate receiver activation followed by a second Telegram
setup.
