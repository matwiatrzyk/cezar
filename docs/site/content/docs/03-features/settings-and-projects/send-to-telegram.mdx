A Telegram receiver posts task notifications to a chat through a bot you create.
Cezar sends a message when a task needs your input, reaches review, finishes,
fails or is cancelled. Start the server with `CEZ_WEBHOOKS=1` to use it.

## Where to find it

Settings → Webhooks → **Add receiver** → **Telegram chat (bot)**

## How to use it

1. Create a bot with BotFather in Telegram and copy its token. Paste the token into the receiver form.
2. Press **Connect chat**. Open the private-chat or group link Cezar shows and press **Start** in Telegram. The chat ID fills in by itself.
3. Choose the message content, save the receiver, press **Send test**, then **Activate** once the test passes.

> **Good to know**:
> - **Minimal** sends task IDs, statuses and the project ID. **Standard** also sends task titles, questions and error text to the chat.
> - **Activate** stays disabled until a test passes. Only events after activation are sent.
> - The token controls the bot. Cezar keeps it in the project secret store and never shows it again after saving.

## Chats and channels

For a channel, add the bot as an admin allowed to post, then post the code Cezar
shows. You can also type the chat ID by hand: supergroup and channel IDs usually
start with `-100`. A bot cannot open a private conversation, so press **Start**
in the private chat first.

**Connect chat** reads the bot's pending messages for up to two minutes while the
form is open. A bot already used by another app cannot connect this way, so use a
bot dedicated to Cezar.

## Messages

Messages show the task status in words, for example
`Status: Waiting for your answer (was running)`. Task text is escaped, link
previews are off and each message stays within Telegram's 4,096-character limit.
A revoked token, a removed bot or an unknown chat disables the receiver. Edit the
receiver, send a test and activate it again.

Notifications need nothing more. To check that a saved token still works, open
**Two-way Telegram**, choose **Start guided setup** with **Notifications only**,
then **Check bot token**; it pairs nobody and can **Send test notification**.
To answer waiting tasks or start tasks from the same chat, choose **Task control**
in [two-way Telegram](/docs/features/settings-and-projects/telegram-replies).
